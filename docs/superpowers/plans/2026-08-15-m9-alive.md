**Goal:** Answer the v1 user review — creatures visibly walk/hop/fly/swim instead of gliding, the camera can never show bare background and feels responsive, fullscreen has an affordance, and the sim's life moments (feeding, brooding, mourning, hatching) become readable at every zoom.

Seeded balance thresholds may be re-baselined ONLY in that task, each with a written root-cause justification; the determinism replay test passes unchanged always.

**Tech Stack:** PixiJS v8, existing sim/render/rigs/ui, Vitest for sim changes.

**Spec:** docs/superpowers/reviews/2026-08-15-v1-user-review.md (feedback, root causes with file:line, decisions) + docs/superpowers/specs/2026-08-13-beastoria-v1-design.md (§4 gentle aesthetic still binds).

## Global Constraints

- `src/sim/` purity as ever (no Pixi/DOM/Math.random/Date.now; seeded sfc32 only; creatures iterated in array order; WorldState stays a serializable POJO with NO new fields — save format stays v2, no migration).
- The determinism test (save-mid-run replay equivalence) must pass UNCHANGED in every task. Balance/seeded thresholds may change only in Task 3 with per-change root-cause justification in the task report; property BANDS may not weaken except where a new hard guarantee (enforced hardCap) replaces a probabilistic one.
- Render rules: no live filters; textures baked once; no per-frame allocation in hot paths; gentle aesthetic (nothing flashes, nothing moves fast; effects periods ≥ 2s; flight/swim presentation calm, not arcadey).
- Rigs are TS data; stages = parametric overrides. New clips/tracks are data edits in existing rig files, never a new art system.
- Testing policy: sim + persist tests only; rendering is eyeballed (report honestly what was verified and how).
- Commits end with trailer `Co-Authored-By: Claude Fable 5 <noreply@anthropic.com>`.

### Task 1: Camera honesty & feel + fullscreen (render/ui only)

**Files:** Modify src/render/Camera.ts, src/render/Renderer.ts, src/app/GameLoop.ts, src/main.ts, src/ui/Hud.ts

**Interfaces:** Produces a camera that mathematically cannot show off-world background, dt-normalized damping, deltaMode-aware wheel, single render loop, and `Hud.setFullscreen(handler)` wiring a ⛶ pill.

- [ ] **Step 1: Zoom-aware pan clamp.** Replace the ±200 fixed-margin clamp in `clampTarget()`:

```ts
const cw = this.canvas.clientWidth, ch = this.canvas.clientHeight;
this.targetZoom = clamp(this.targetZoom, this.minZoom(), MAX_ZOOM);
const halfW = cw / 2 / this.targetZoom;
const halfH = ch / 2 / this.targetZoom;
this.targetX = halfW * 2 >= WORLD_WIDTH ? WORLD_WIDTH / 2 : clamp(this.targetX, halfW, WORLD_WIDTH - halfW);
this.targetY = halfH * 2 >= WORLD_HEIGHT ? WORLD_HEIGHT / 2 : clamp(this.targetY, halfH, WORLD_HEIGHT - halfH);
```

Apply the same clamp (using `this.zoom`) to `this.x/this.y` after the damping step so overshoot can't flash background either. Read `clientWidth/clientHeight` ONCE per `update()` into locals shared with `minZoom()` (pass them in) — kills the 4 layout reads/frame.
- [ ] **Step 2: dt-normalized damping + wheel normalization.** `const k = 1 - Math.pow(1 - ZOOM_DAMP, dtMs / 16.67)` (Camera.update gains a dtMs param — Renderer.render already has dtMs). Wheel: `const px = e.deltaMode === 1 ? e.deltaY * 33 : e.deltaMode === 2 ? e.deltaY * ch : e.deltaY;` then `Math.exp(-px * 0.002)`. Keep cursor-anchored zoom math.
- [ ] **Step 3: Single render loop.** `Application.init({ ..., autoStart: false })`; GameLoop's render callback ends with `renderer.renderFrame()` → `app.render()` after camera/ambient updates. Verify nothing else depended on the ticker (CallScheduler/mixer run off sim ticks — confirm, note in report).
- [ ] **Step 4: Fullscreen pill.** Hud gains a third pill "⛶" (title "fullscreen", `data-testid="fullscreen-chip"`, role=button, hidden when `!document.fullscreenEnabled`): toggles `document.documentElement.requestFullscreen()` / `document.exitFullscreen()`; label/title flips on `fullscreenchange`. Window resize path already keeps canvas + minZoom honest (Pixi resizeTo + per-frame clamp).
- [ ] **Step 5: Gates + eyeball.** `npm test` (120/120 untouched), lint, build. Dev-server: drag hard at min zoom on wide + narrow windows — zero background visible ever; wheel-zoom feels responsive; fullscreen toggles edge-to-edge.
